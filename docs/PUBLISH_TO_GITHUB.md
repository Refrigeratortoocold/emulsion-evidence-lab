## Work locally with git

Clone the existing repository rather than creating a second repository or
overwriting its history. Supply your own git authentication when requested.

```bash
git clone https://github.com/Refrigeratortoocold/emulsion-evidence-lab.git
cd emulsion-evidence-lab
# Make your changes and run the offline verification before committing.
git add .
git commit -m "Describe your actual change"
git push
```

The offline tests and command-line demo are documented in the main README.
